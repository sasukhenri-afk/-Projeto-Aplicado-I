🚇 Projeto Aplicado — Metrô de São Paulo
📊 Data Storytelling e Análise de Dados

Projeto acadêmico desenvolvido em grupo para a disciplina de Projeto Aplicado, da Universidade Presbiteriana Mackenzie.

O projeto tem como foco a análise de dados relacionados ao Metrô de São Paulo, utilizando técnicas de análise, visualização e Data Storytelling para transformar dados em informações relevantes e facilitar a compreensão dos resultados.

🎯 Objetivo do Projeto

O principal objetivo é utilizar dados públicos relacionados ao Metrô de São Paulo para identificar padrões, comportamentos e informações relevantes sobre sua operação e, a partir disso, construir uma narrativa baseada em dados.

A proposta combina análise de dados + visualização + storytelling, buscando apresentar os resultados de maneira clara, objetiva e compreensível.

🏢 Empresa Analisada

Metrô de São Paulo — Companhia do Metropolitano de São Paulo

O Metrô é uma empresa estatal responsável pela operação e administração de parte do sistema metroviário da cidade de São Paulo.

Neste projeto, serão analisados dados relacionados à empresa e/ou ao sistema metroviário, buscando compreender aspectos de sua operação e apresentar os principais insights encontrados por meio da análise de dados.

📖 Data Storytelling

O Data Storytelling é uma abordagem que combina dados, visualizações e narrativa para comunicar informações de maneira mais eficiente.

Neste projeto, a análise não se limita à apresentação de gráficos e números. A intenção é construir uma história a partir dos dados, respondendo a perguntas como:

O que os dados estão mostrando?
Quais padrões podem ser identificados?
Existem mudanças relevantes ao longo do tempo?
Quais fatores podem explicar os resultados?
Quais são os principais insights obtidos?
Como essas informações podem ser interpretadas no contexto do Metrô?
🔎 Metodologia

O desenvolvimento do projeto seguirá etapas de:

Definição do problema
Pesquisa sobre o Metrô de São Paulo
Coleta dos dados
Tratamento e organização dos dados
Análise exploratória
Identificação de padrões e tendências
Criação de visualizações
Construção da narrativa baseada em dados
Apresentação dos principais insights
Conclusão
